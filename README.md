# FastInvest
Projeto Integrador Digital House, modernizado em Astro + Tailwind 4 (site de demonstração de estudo).

- `npm install`, `npm run dev`, `npm run check`, `npm run build` (saída em `dist/`).
- Site em https://fastinvest.libertycondominio.online
- Os arquivos originais (Bootstrap) ficam em `referencias/original/`, fora do build.
